
# HR ANALYTICS DASHBOARD

## DESCRIPTION
Data visualization project developed using Microsoft Power BI to analyze employee data and understand workforce attrition patterns. The dashboard provides valuable insights into employee demographics, departmental distribution, salary groups, work experience, and employee turnover.

# PROJECT OBJECTIVES
Analyze total employees, active employees, and employee attrition.
Calculate and monitor the employee attrition rate.
Understand employee distribution across departments and job roles.
Analyze attrition patterns by salary group and work experience.
Explore employee demographics based on age and gender.
Support HR teams in developing employee retention strategies.

# TOOLS AND TECHOLOGIES USED

Microsoft Power BI: Dashboard creation and data visualization.
Power Query: Data cleaning and transformation.
DAX: Calculating KPIs and analytical measures.
Excel/CSV: Data storage and preparation.

# DASHBOARD FEATURES
KPI Cards: Total employees, active employees, attrition count, attrition rate, average age, and average experience.
Department Analysis: Employee distribution and attrition across departments.
Salary Analysis: Comparison of attrition across salary groups.
Age Group Analysis: Workforce distribution across different age categories.
Experience Analysis: Employee attrition trends based on work experience.
Gender Analysis: Employee distribution by gender.
Job Role Analysis: Comparison of employee attrition across different job roles.

# KEY INSIGHTS

The dataset contains approximately 1,417 employees.
The dashboard reports 231 employee attritions.
The displayed attrition rate is 16.3%.
The average employee age is approximately 36.94 years.
The average work experience is approximately 7.04 years.
Operations and Administration have the highest employee counts among the departments shown.
Interactive Filters: Department and age-group slicers for customized analysis.
